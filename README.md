# AIpdf

会計Plus「一括アップロード」のAI分割機能、案2の動的プロトタイプです。

- メイン画面: 1354 × 671
- Preview: 1298 × 695
- ブラウザの表示領域に合わせて自動縮小
- フォント: Meiryo
- メイン画面: `case2.html`
- 分割完了状態: `case2.html?demo=ready`
- Preview表示状態: `case2.html?demo=preview`
- 実装: `case2.css` / `case2.js`

## 操作

1. `AIで分割` を押す
2. 現在画面で分割中状態を表示
3. 分割完了後、`プレビュー` からダイアログを開く
4. ファイル名変更、ページ削除、分割、結合、再分割を操作する
5. `保存` で現在画面へ戻る

既存の `index.html` と `preview-result.html` は旧検討版として残しています。
